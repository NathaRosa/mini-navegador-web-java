# Mini Navegador Web Java

Mini navegador web desenvolvido em Java utilizando JavaFX.

O projeto tem como objetivo explorar a criação de uma aplicação desktop capaz de carregar e navegar por páginas da web, além de praticar conceitos relacionados a interfaces gráficas, componentes JavaFX e gerenciamento de eventos.

## Funcionalidades

* Navegação entre páginas da web.
* Campo para inserção de URLs.
* Carregamento de páginas utilizando JavaFX.
* Botão para acessar endereços informados.
* Interface gráfica para interação com o navegador.
* Exibição do conteúdo das páginas dentro da aplicação.

* Java
* JavaFX
* JavaFX WebView

## Objetivo

Projeto desenvolvido para praticar desenvolvimento de aplicações desktop em Java, com foco em interfaces gráficas, gerenciamento de eventos e utilização dos componentes de navegação disponibilizados pelo JavaFX.

O projeto também serve como base para explorar conceitos relacionados a navegadores web e aplicações que utilizam mecanismos de renderização de páginas.
